# Imobiliária Extremo Oriente Landing Page

## 📄 Descrição

Este repositório contém a landing page **Imobiliária Extremo Oriente**, desenvolvida como um site estático para apresentar o catálogo de imóveis de alto padrão. A página foi construída com foco em design premium, utilizando:

- **HTML5** para a estrutura semântica;
- **CSS3** com variáveis customizadas (tema escuro, cores douradas, animações suaves);
- **JavaScript (ES6 modules)** para interatividade mínima e carregamento do módulo principal.

O objetivo é oferecer uma experiência visual rica, com micro‑animações, efeitos de glassmorphism e layout responsivo.
